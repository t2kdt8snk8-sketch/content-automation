# Content Automation 워크플로우

## 한 줄 요약

리서치 자동 수집 → 기회 카드 생성 → 내가 승인 → Gemini로 콘텐츠 제작


## 전체 흐름

서버를 켜면 백그라운드에서 3개 루프가 자동으로 돌기 시작한다. 이게 시스템의 심장이다. 루프들이 데이터를 쌓으면 AI가 분석해서 기회 카드를 만들고, 나는 카드를 보고 괜찮은 것만 골라서 제작으로 넘기는 구조다.


## 1단계 — 자동 리서치 수집 (30분마다)

`scheduler.py`의 research_loop가 30분마다 실행된다. SCAN_CATEGORIES에 설정한 카테고리(현재 black music culture, fashion, jazz)별로 5개 소스에서 동시에 데이터를 긁어온다.

수집하는 소스:
- DuckDuckGo — 웹 검색 결과 (뉴스 포커스)
- NewsAPI — 영어 뉴스 기사
- Reddit — 커뮤니티 반응, 점수 높은 포스트
- YouTube — 최신 영상 제목과 설명
- Pytrends — Google 트렌드 상승 키워드 (자주 막혀서 건너뜀 처리됨)

수집된 결과는 `outputs/research/` 폴더에 JSON으로 저장된다. 각 카테고리별로 별도 파일이 생긴다.


## 2단계 — 트렌드 스캔 (6시간마다)

`scanner_agent`가 카테고리별로 "지금 뭐가 뜨고 있는가"를 분석한다. 리서치 수집보다 훨씬 덜 자주 돌고, 더 넓은 시각으로 트렌드를 잡는다. 결과는 `outputs/trends/`에 저장된다.


## 3단계 — 기회 카드 생성 (60분마다)

`strategy_agent`가 쌓인 리서치를 보고 "이게 콘텐츠로 만들 만한가"를 판단한다. 새 리서치가 3건 이상 있을 때만 실행된다 (너무 자주 돌지 않게).

카드 하나에 들어가는 정보:
- 제목과 요약 (왜 지금 이 주제인가)
- 근거 (어떤 소스에서 뭘 봤는지)
- 추천 포맷 (카드뉴스, 카피, 스크립트 등)
- 추천 각도 (어떤 방향으로 풀 수 있는지)
- 기회 점수 (0-100)

카드가 만들어지는 순간 WebSocket으로 프론트에 바로 전송된다. 새로고침 없이 피드 탭에 즉시 뜬다. 카드는 `outputs/opportunities/`에 JSON으로 저장된다.


## 4단계 — 피드 탭에서 카드 검토 (내가 함)

피드 탭에 쌓인 카드들을 본다. 각 카드마다 "왜 지금인지", 점수, 포맷 추천이 표시된다. 궁금한 게 있으면 카드 안에서 바로 채팅 가능하다. AI가 카드 컨텍스트를 알고 있어서 "이 트렌드 얼마나 갈 것 같아?" 같은 걸 물어볼 수 있다.

판단하면 승인 또는 패스. 승인된 카드만 제작 탭에 표시된다.


## 5단계 — 제작 탭에서 콘텐츠 제작 (내가 시작, AI가 만듦)

승인된 카드를 선택하면 제작이 시작된다.

**포맷 분석** — Gemini Flash(빠른 모델)가 카드 내용을 보고 어떤 포맷이 맞는지 판단한다. 동시에 DuckDuckGo 이미지 검색으로 관련 이미지도 자동으로 가져온다. 결과를 채팅으로 제안한다.

예: "카드뉴스 포맷을 추천합니다. 이 트렌드는 통계와 비교가 핵심이라 시각화가 효과적입니다. 구성: 후크 → 현황 → 왜 지금 → CTA"

**방향 조율** — 제안이 마음에 안 들면 채팅으로 바꿀 수 있다. "릴스 대본으로 바꿔줘", "톤 더 캐주얼하게", "영어로 써줘" 같은 식으로. 이 내용이 다음 단계에 반영된다.

**제작 시작** — Gemini Pro(본 제작 모델)가 실제 콘텐츠를 생성한다. 이미지 URL도 어느 섹션에 쓰면 좋은지 언급해준다.


## AI가 사용하는 모델

리서치 수집과 전략 분석은 NIM 프록시를 통해 Claude 계열 모델을 쓴다. NIM 프록시는 무료로 돌리는 중간 서버인데, 실제로는 kimi-k2.5, qwen3.5 같은 오픈소스 모델로 라우팅된다. 퀄리티는 Claude 직접보다 좀 낮다.

콘텐츠 제작은 Gemini API를 직접 호출한다. 포맷 판단이나 대화같은 빠른 작업은 Flash, 실제 콘텐츠 생성은 Pro를 쓴다.


## 데이터가 저장되는 곳

모든 데이터는 `outputs/` 폴더 아래에 JSON 파일로 쌓인다.

- `outputs/research/` — 리서치 수집 결과
- `outputs/trends/` — 트렌드 스캔 결과
- `outputs/opportunities/` — 기회 카드
- `outputs/results/` — 워크플로우 실행 결과


## 환경변수

반드시 있어야 하는 것:
- `WEB_PASSWORD` — 웹 UI 로그인 비밀번호
- `GEMINI_API_KEY` — 콘텐츠 제작용

있으면 해당 소스가 켜지고, 없으면 그냥 건너뜀:
- `NEWS_API_KEY` — NewsAPI
- `YOUTUBE_DATA_API_KEY` — YouTube
- `REDDIT_CLIENT_ID` / `REDDIT_CLIENT_SECRET` — Reddit (없어도 공개 검색으로 작동함)

바꿀 수 있는 것 (기본값으로 둬도 됨):
- `SCAN_CATEGORIES` — 수집할 카테고리, 쉼표로 구분
- `RESEARCH_INTERVAL_MINUTES` — 리서치 수집 주기 (기본 30분)
- `SCAN_INTERVAL_HOURS` — 트렌드 스캔 주기 (기본 6시간)
- `STRATEGY_INTERVAL_MINUTES` — 기회 카드 생성 주기 (기본 60분)
- `STRATEGY_MIN_NEW_ITEMS` — 카드 생성 트리거 최소 리서치 건수 (기본 3)
