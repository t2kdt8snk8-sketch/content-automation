# 실행 계획 (Execution Plan) — 미국 주식 스윙 자동매매 시스템

> 이 문서는 **무엇을, 어떤 순서로, 어떤 기준으로** 진행할지에 대한 운영 로드맵이다.
> 코드/기술 상세는 `02-implementation-spec.md` 참고.

---

## 0. 한 줄 정의

> **돈을 한 푼도 잃지 않고, "내 단기 스윙 전략이 진짜로 시장(SPY 적립식)보다 나은가"를 숫자로 결판내는 시스템.**

핵심 철학:
- "이긴다"는 미리 보장되지 않는다. **모의투자 성적표가 답을 준다.**
- 화려함이 아니라 **검증과 규율**로 승부한다.
- 18개월 동안 `가설 → 검증 → 측정 → 다음 가설` 사이클을 여러 번 돌린다.

## 2. 보유 스타일 결정

- **데이트레이딩(당일 청산): 제외.** 폰+군 생활로 물리적으로 불가능하고, 개인 승산도 낮음.
- **채택: 스윙 트레이딩 (보유 하루~수주).**
  - 시스템이 미국 장 시간에 규칙대로 매매 → 사용자는 아침에 폰으로 결과 확인.

## 4. 성공의 정의 (이걸로 결판)

수익률만 보지 않는다. 아래 4개 지표를 **SPY 적립식과 직접 비교**한다.

| 지표 | 뜻 (초보용 설명) |
|---|---|
| **CAGR** | 연복리 수익률. "1년에 평균 몇 % 불었나" |
| **MDD** | 최대낙폭. "고점 대비 제일 많이 깨졌을 때 얼마나 깨졌나" (작을수록 좋음) |
| **Sharpe** | 위험 대비 효율. "출렁임 1만큼 감수하고 수익 얼마 얻었나" (클수록 좋음) |
| **승률** | 이긴 거래 비율 (참고용. 단독 판단 금지) |

**실전 전환 통과선:**
- **거래비용·슬리피지·세금을 전부 떼고도**,
- 워크포워드(안 본 구간) + 모의 3개월에서,
- SPY 적립식보다 **Sharpe가 높거나**, **비슷한 수익에 MDD가 확실히 낮을 것.**

## 5. 사용자가 직접 할 일 (병렬 진행 가능)

1. **Alpaca 페이퍼 계정** 가입 → `API Key` / `API Secret` 확보 (실전 아닌 paper 키)
2. **텔레그램 봇** 생성 (BotFather) → `봇 토큰` + 본인 `chat id` 확보
3. 위 값들은 **GitHub Secrets**에 저장 (코드에 절대 직접 입력 금지)

---

## 6. 18개월 활용 원칙

- 한 사이클(전략 구현 → 검증 → 모의 → 측정)을 **여러 번 반복**한다.
- 전략이 깨지면(게이트 탈락) 좌절이 아니라 **데이터 확보**다. 다음 가설로 간다.
- 최종 산출물은 "돈"이기 이전에 **데이터·자동화·금융을 다루는 실력**이다. 그게 전역 후 가장 큰 자산.

---

## 7. 리스크 / 주의 (반드시 인지)

- 단기 전략은 **백테스트 대박 → 실전 폭망**이 가장 흔하다 (과최적화).
- 그래서 워크포워드 검증과 모의 3개월을 **건너뛰지 않는다.**
- 시스템은 규칙을 실행할 뿐, **"이 좋은 성적이 진짜냐 우연이냐"를 의심하는 건 사람의 몫**이다.
- 실전 전환은 게이트 통과 후 **반드시 소액부터.**
