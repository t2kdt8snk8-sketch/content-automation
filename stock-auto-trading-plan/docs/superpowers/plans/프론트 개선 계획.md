백엔드 vs 화면 비교 — 안 보이는 것 정리
1. 화면에 전혀 없는 기능 (백엔드만 존재)
이벤트(뉴스/공시) 데이터

백엔드: 종목별 이벤트 CSV 파서 + DB 테이블 + AI 의견서 생성 시 최근 이벤트 5건 자동 참조
화면: 업로드 페이지에 관심종목/가격 CSV 폼만 있음. 이벤트 업로드 폼·이벤트 목록 페이지 없음
결과: 의견서가 이벤트를 활용 할 수도 있는데 사용자가 이벤트를 넣을 길이 없음
학습 노트 (실패 회고)

백엔드: 실패 사유, 증거, 신뢰도(확정/추정/가설), 규칙 변경 제안 저장하는 테이블+저장 함수 다 있음
화면: 작성 폼도, 목록 페이지도 없음. 호출하는 코드도 없음 → 완전 죽은 기능
모델 버전 관리

백엔드: 모델 후보 등록 → 사용자 승인 → 활성 승격 흐름 다 구현
화면: 대시보드에 "활성 모델" 이름 한 줄만 표시. 후보 모델 목록도, 승급 버튼도 없음
결과: 승급은 DB 직접 건드려야만 됨
텔레그램 연결 상태

백엔드: 봇 발송, 콜백 승인/거절 처리, 웹훅 라우트 존재
화면: 봇 연결 상태, 채팅 ID 등록, 웹훅 URL 안내 화면 없음. 메모 상세에 "텔레그램" 버튼만 있음
자동 스케줄러

백엔드: 매일 정해진 시간에 수집→피처→후보→학습→AI의견서→성과 자동 실행
화면: 자동 모드 ON/OFF, 다음 실행 시각, 마지막 자동 실행 결과 표시 없음. 사용자가 수동으로만 돌리는 줄 앎
app/web/routes.py app/scheduler.py app/events/ingest.py app/reports/learning_notes.py app/learning/model_registry.py

2. 부분만 보이는 기능 (계산은 다 되는데 일부만 노출)
수학 검증 탭 — memo_detail.html:122-138

화면 표시: 확률 상태, 점수, 손익분기 확률, 보정 확률, 기대값, 손익비, 제안 비중, 비용 스트레스 통과 여부
계산은 됐는데 안 보임:
비용 민감도 표 — 거래비용 0.1% / 0.3% / 0.5% 각각의 기대값 시나리오 (어디까지 비용이 늘어도 수익 나는지)
상승폭/하락폭 절대값 (gain/loss)
학습 표본 수, 보정 표본 수 (확률을 몇 개 표본으로 추정했는지)
결정 모드 — "승인 가능 / 모의 추적만 / 차단" 3단계 플래그가 따로 계산되는데 화면엔 위험상태로만 합쳐 보임
위험 게이트 — app/risk/rules.py

백엔드는 4단계 반환: 정상 / 경고(승인은 가능) / 모의 추적만 / 차단
화면은 사실상 "차단됨" vs "정상" 2단계로만 보임. 경고/모의 추적 구분 없음
메모 만료 정보 — DB에 저장됨

유효기한 시각, 진입가에서 얼마까지 벗어나면 무효(기본 1.5%), 이벤트 발생 시 무효화 여부
화면에 일절 표시 안 됨 → 사용자는 의견서가 언제까지 유효한지 모름
승인 이력

백엔드: 승인/거절할 때마다 누가/언제/어느 채널(웹/텔레그램)인지 이력 테이블에 기록
화면: 현재 상태 한 줄만. 이력 안 보임
AI 멀티 프로바이더 응답

백엔드: 의견서 만들 때 여러 AI에게 동시에 물어보고 그 원본 응답들을 다 저장
화면: 어느 AI가 어떤 답을 줬는지 못 봄. 최종 합쳐진 결과만 보임
성과 스냅샷

백엔드: 5일 / 10일 / 20일 세 기간으로 사후 수익률 계산
화면: 대시보드에 10일짜리만 표시. 5일·20일 안 보임
AI 품질 요약

백엔드: 강한 매수 의견 평균 보수적 수익률, "관망"인데 시장을 이긴 건수 등 계산
화면: 강한 매수 건수 1개만 표시
점수 레이더

DB에 점수 6종(가격추세/실적/뉴스/수급/위험/손익비) 저장
레이더 차트는 5축만 그림. "위험 점수"는 빠짐
데이터 신뢰도

백엔드: 상태 + 이유 메시지 리스트 함께 반환
화면: 상태 단어만. 이유(예: SPY 데이터 없음 / 수정주가 누락) 안 보임
3. 죽은 코드 (백엔드에 구현됐지만 어디서도 호출 안 됨)
호출 흔적 0건 — 사용자에게도, 다른 코드에도 영향 없음:

학습용 시계열 분할 도구 (훈련 구간/테스트 구간을 시간 누수 없이 나누는 로직)
확률 보정 평가지표 3종 (Brier, log loss, ECE) — 모델이 잘 보정됐는지 측정
점수 구간별 단조성 검증 (점수 높을수록 진짜 수익 나는지 검사)
계수 부호 안정성, 기간 수익 집중도 분석
평균 신뢰구간 95% 계산
학습 노트 작성 함수, 모델 후보 등록·승급 함수, 이벤트 CSV 입력 함수
